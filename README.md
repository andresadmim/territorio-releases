# Territorio - Descargas

Instalador oficial de **Territorio** (gestion de territorios y predicacion).

## Descargar

[Ultima version (TerritorioSetup.exe)](https://github.com/andresadmim/territorio-releases/releases/latest)

## Instalacion

1. Descargar `TerritorioSetup.exe` desde la ultima release.
2. Ejecutarlo y elegir la carpeta de instalacion.
3. Se crean accesos directos en el Escritorio y en el Menu Inicio.
4. Abrir **Territorio**. Usuario: `admin` - Contrasena: `admin`
   (cambiar la contrasena desde la pantalla de Usuarios).

La base de datos empieza vacia. Los accesos directos se pueden quitar con
`Desinstalar.bat`, dentro de la carpeta de instalacion.
