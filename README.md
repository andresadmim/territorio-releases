# Territorio - Descargas

Instalador oficial de **Territorio** (gestion de territorios y predicacion).

## Descargar

- [Ultima version en ZIP (recomendado)](https://github.com/andresadmim/territorio-releases/releases/latest)
- El ZIP incluye el instalador y un LEEME con los pasos.

## Instalacion

1. Descargar el ZIP de la ultima release y descomprimirlo.
2. Ejecutar `TerritorioSetup.exe`.
3. Elegir la carpeta de instalacion y esperar al 100%.
4. Se crean accesos directos en el Escritorio y en el Menu Inicio.
5. Abrir **Territorio**. Usuario: `admin` - Contrasena: `admin`
   (cambiar la contrasena desde la pantalla de Usuarios).

La base de datos empieza vacia. Los accesos directos se pueden quitar con
`Desinstalar.bat`, dentro de la carpeta de instalacion.

### Aviso de Windows

El instalador no tiene firma digital de pago, por lo que Windows puede
mostrar "Windows protegio tu PC". Elegir **Mas informacion** y luego
**Ejecutar de todas formas**.
